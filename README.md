# GT-ToneMapping
Fork of **yaoling1997*'s unity shader implementation of [Gran Turismo Tonemapping](https://www.desmos.com/calculator/gslcdxvipg?lang=zh-CN).

How to use:
1. Create a material from the shader file by right clicking > Create > Material
2. Add a new Full Screen Renderer Pass Feature to your URP Asset
